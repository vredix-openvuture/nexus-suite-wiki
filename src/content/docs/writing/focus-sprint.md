## Focus

Command **Toggle focus mode**. It starts off.

| Setting | Default | |
|---|---|---|
| Dim | on | Dim everything but the current scope |
| Scope | `line` | `line` · `sentence` · `paragraph` |
| Dim opacity | 45 | How far the rest fades |
| Typewriter | off | Keeps the current line at a fixed height on screen |
| Typewriter offset | 50 | Where that line sits, as a percentage |
| Sound | off | A key sound while typing |
| Sound style | `soft` | |
| Volume | 25 | |
| Bell | off | A bell at the end of a line |

## Sprints

Command **Start a writing sprint**. Timed writing against a word goal, with
either or both as the target.

| Setting | Default |
|---|---|
| Minutes | 15 |
| Words | 300 |
| Use time | on |
| Use words | on |
| Status bar | on |
| Focus during the sprint | off |
| Done message | — |

With both targets on, the sprint ends when either is met. The status bar shows
whichever is closer.

**Focus during the sprint** turns focus mode on for the duration and off again
afterwards, so it does not have to be remembered in both directions.

**Stop the writing sprint** ends one early.

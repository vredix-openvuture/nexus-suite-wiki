## What is here

<CardGrid>
	<Card title="Twenty-six modules" icon="puzzle">
		Each one has a switch. A module that is off costs nothing: no listeners,
		no styles, no commands. See [One switch per module](/concepts/modules/).
	</Card>
	<Card title="Blocks that are their data" icon="document">
		A kanban board, a planner and an agenda live inside their own fence in a
		note. They survive without the plugin and travel with the file.
	</Card>
	<Card title="Mobile as well as desktop" icon="phone">
		One bundled file, no runtime require of sibling modules. Where something
		genuinely cannot run on a phone, the docs say so rather than leaving a
		button that does nothing.
	</Card>
	<Card title="Nothing leaves the machine" icon="approve-check">
		Handwriting recognition and speech run programs you installed. The vault
		sync talks to your server. There is no service in the middle.
	</Card>
</CardGrid>
